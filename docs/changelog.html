版本 1.0.1

2025-07-18 补丁版本

🐛 错误修复

  • 修复语法错误 - 修复 class-taxonomy-event-handler.php 第433行多余的右大括号导致的PHP解析错误
  • 修复分类法索引页刷新问题 - 修复文章状态更新后，category、tag和自定义分类法条目索引页的文章数量没有同步刷新的问题

🔧 改进项目

  • 完善缓存失效逻辑 - 在文章插入、删除、状态变化时正确调用分类法缓存失效方法
  • 增强WebSocket事件通知 - 添加分类法更新的WebSocket事件通知，确保前端页面能及时更新文章数量
  • 优化事件处理流程 - 改进文章状态变化时的事件处理逻辑，确保所有相关页面都能收到更新通知

📝 技术细节

  • 修复的文件：
    • includes/class-taxonomy-event-handler.php - 修复语法错误
    • includes/class-cache-invalidator.php - 完善缓存失效和事件通知逻辑
  • 新增方法：
    • notify_taxonomy_updates_for_post() - 发送分类法更新的WebSocket事件
  • 改进的方法：
    • invalidate_caches_on_post_insert() - 添加分类法缓存失效调用
    • invalidate_caches_on_post_delete() - 添加分类法缓存失效调用
    • invalidate_caches_on_post_status_change() - 添加分类法缓存失效调用

🎯 影响范围

  • 分类法索引页 - category-index-page、tag-index-page等索引页面现在能正确更新文章数量
  • 分类法条目页 - 具体的分类、标签、自定义分类法页面能正确更新文章数量
  • WebSocket事件 - 前端能收到分类法更新事件，实现实时刷新
  • 缓存失效 - Next.js缓存能正确失效，确保数据一致性

⚡ 升级说明

  • 无需配置变更 - 此版本为纯错误修复，无需修改任何配置
  • 即时生效 - 更新插件后立即生效，无需额外操作
  • 向后兼容 - 完全兼容现有功能，不影响已有的事件处理

版本 1.0.0

2024-01-15 重大版本

🎉 重大重构

从单一文件 fd-pusher 插件重构为模块化的 fd-websocket-push 插件。

✨ 新增功能

  • 模块化架构 - 将单一 1656 行文件拆分为 7 个专门的类文件
  • 单例模式 - 所有处理器类采用单例模式，提高资源效率
  • 向后兼容 - 提供全局函数包装器，确保旧代码继续工作
  • 详细文档 - 完整的 HTML 文档系统，包含 API 参考和使用示例
  • 错误处理增强 - 更完善的错误处理和日志记录机制

🔧 改进项目

  • 代码组织 - 清晰的职责分离，每个类专注于特定功能
  • 性能优化 - 优化了事件处理流程，减少重复代码
  • 可维护性 - 更好的代码结构，便于后续维护和扩展
  • 日志系统 - 统一的日志记录格式和级别管理

📁 文件结构

fd-websocket-push/
├── fd-websocket-push.php              # 主插件文件
├── includes/
│   ├── class-helper.php               # 辅助工具类
│   ├── class-cache-invalidator.php    # 缓存失效处理类
│   ├── class-websocket-pusher.php     # WebSocket推送处理类
│   ├── class-post-event-handler.php   # 文章事件处理类
│   ├── class-taxonomy-event-handler.php # 分类法事件处理类
│   └── class-payment-event-handler.php  # 支付事件处理类
├── docs/                              # 完整文档系统
└── README.md                          # 说明文档

🔄 迁移说明

  • 零配置变更 - 使用相同的配置常量
  • 零功能丢失 - 所有原有功能都已完整迁移
  • 平滑迁移 - 提供详细的迁移指南
  • 回滚支持 - 可以随时回滚到旧版本

🛡️ 兼容性

  • WordPress - 兼容 WordPress 5.0+
  • PHP - 兼容 PHP 7.4+
  • ACF - 完整支持 Advanced Custom Fields 插件
  • 向后兼容 - 提供 fd_pusher_* 函数包装器

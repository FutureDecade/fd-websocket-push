API 参考

核心类概览

FD_WebSocket_Push 主插件类，负责初始化和组件管理
FD_WebSocket_Push_Helper 辅助工具类，提供通用功能和验证
FD_WebSocket_Push_Cache_Invalidator 缓存失效处理类
FD_WebSocket_Push_WebSocket_Pusher WebSocket 推送处理类
FD_WebSocket_Push_Post_Event_Handler 文章事件处理类
FD_WebSocket_Push_Taxonomy_Event_Handler 分类法事件处理类
FD_WebSocket_Push_Payment_Event_Handler 支付事件处理类

FD_WebSocket_Push_Helper 类

静态方法

is_websocket_push_enabled()

返回: bool - WebSocket 推送是否已启用

描述: 检查 FD_WEBSOCKET_PUSH_SECRET 常量是否已定义且不为空

if ( FD_WebSocket_Push_Helper::is_websocket_push_enabled() ) {
    // WebSocket 推送已启用
}
is_revalidation_enabled()

返回: bool - 缓存失效是否已启用

描述: 检查 REVALIDATE_SECRET 常量是否已定义且不为空

if ( FD_WebSocket_Push_Helper::is_revalidation_enabled() ) {
    // 缓存失效已启用
}
get_websocket_push_secret()

返回: string|null - WebSocket 推送密钥

描述: 获取 WebSocket 推送密钥，如果未定义则返回 null

get_revalidation_secret()

返回: string|null - 缓存失效密钥

描述: 获取缓存失效密钥，如果未定义则返回 null

is_public_post_type( $post_type )

参数: string $post_type - 文章类型名称

返回: bool - 文章类型是否为公开类型

描述: 检查指定的文章类型是否为公开类型

if ( FD_WebSocket_Push_Helper::is_public_post_type( 'post' ) ) {
    // 'post' 是公开文章类型
}
is_public_taxonomy( $taxonomy )

参数: string $taxonomy - 分类法名称

返回: bool - 分类法是否为公开类型

描述: 检查指定的分类法是否为公开类型

get_post_access_level( $post_id, $post )

参数:

  • int $post_id - 文章 ID
  • WP_Post $post - 文章对象

返回: string - 访问级别 ('public', 'authenticated_users', 'level_X')

描述: 根据文章的访问权限设置确定 WebSocket 推送的目标房间

should_ignore_meta_key( $meta_key )

参数: string $meta_key - 元数据键名

返回: bool - 是否应该忽略此元数据键

描述: 检查元数据键是否应该被忽略（如内部字段、临时数据等）

log( $message, $level = 'DEBUG' )

参数:

  • string $message - 日志消息
  • string $level - 日志级别（可选，默认 'DEBUG'）

描述: 记录带有插件前缀的日志消息

FD_WebSocket_Push_Helper::log( 'Custom message', 'INFO' );
// 输出: [FD WebSocket Push INFO] Custom message

FD_WebSocket_Push_Cache_Invalidator 类

get_instance()

返回: FD_WebSocket_Push_Cache_Invalidator - 单例实例

描述: 获取缓存失效处理器的单例实例

revalidate_tag( $tag )

参数: string $tag - 缓存标签

描述: 向 Next.js 发送标签缓存失效请求

$cache_invalidator = FD_WebSocket_Push_Cache_Invalidator::get_instance();
$cache_invalidator->revalidate_tag( 'homepage-posts' );
revalidate_path( $path )

参数: string $path - 路径

描述: 向 Next.js 发送路径缓存失效请求

$cache_invalidator->revalidate_path( '/category/technology' );
revalidate_term_caches( $term )

参数: WP_Term $term - 分类法条目对象

描述: 失效指定分类法条目的所有相关缓存

invalidate_post_caches( $post_id, $post )

参数:

  • int $post_id - 文章 ID
  • WP_Post $post - 文章对象

描述: 失效文章相关的缓存

FD_WebSocket_Push_WebSocket_Pusher 类

get_instance()

返回: FD_WebSocket_Push_WebSocket_Pusher - 单例实例

描述: 获取 WebSocket 推送器的单例实例

send_event( $event_type, $target, $data = [] )

参数:

  • string $event_type - 事件类型
  • string $target - 目标房间
  • array $data - 事件数据（可选）

返回: bool|WP_Error - 发送结果

描述: 向 WebSocket 服务器发送事件

$pusher = FD_WebSocket_Push_WebSocket_Pusher::get_instance();
$result = $pusher->send_event( 'custom:event', 'public', [
    'message' => 'Hello World'
] );
send_post_updated_event( $post_id, $post )

参数:

  • int $post_id - 文章 ID
  • WP_Post $post - 文章对象

描述: 发送文章更新事件

send_taxonomy_updated_event( $event_type, $term_id, $taxonomy )

参数:

  • string $event_type - 事件类型
  • int $term_id - 分类法条目 ID
  • string $taxonomy - 分类法名称

描述: 发送分类法更新事件

向后兼容函数

为了保持与旧版本的兼容性，插件提供了以下全局函数：

fd_pusher_revalidate_tag( $tag )

参数: string $tag - 缓存标签

描述: 向后兼容的缓存标签失效函数

// 旧版本兼容调用
fd_pusher_revalidate_tag( 'homepage-posts' );
fd_pusher_revalidate_tag_for_term( $term )

参数: WP_Term $term - 分类法条目对象

描述: 向后兼容的分类法条目缓存失效函数

自定义过滤器

插件提供了以下自定义过滤器供开发者使用：

fd_websocket_push_server_url

描述: 自定义 WebSocket 服务器 URL

add_filter( 'fd_websocket_push_server_url', function( $url ) {
    return 'http://custom-websocket-server:8080/push-event';
} );
fd_websocket_push_frontend_url

描述: 自定义前端服务器 URL

add_filter( 'fd_websocket_push_frontend_url', function( $url ) {
    return 'http://custom-frontend-server:3000';
} );
fd_websocket_push_enable_post_events

描述: 启用/禁用文章事件

// 禁用文章事件
add_filter( 'fd_websocket_push_enable_post_events', '__return_false' );

插件概述

⚡

实时推送

当 WordPress 事件发生时，立即向 WebSocket 服务器发送实时通知

🔄

缓存管理

自动失效 Next.js 缓存，确保前端内容始终保持最新

🎯

精准推送

基于用户权限和内容访问级别的精准推送通知

🧩

模块化设计

清晰的代码结构，易于维护和扩展

主要功能

  • 文章生命周期事件 - 文章创建、更新、删除、状态变化
  • 分类法事件 - 标签、分类、自定义分类法的增删改
  • 元数据更新 - 支持 ACF 字段和自定义字段
  • 支付解锁事件 - 文章付费解锁成功通知
  • 列表更新通知 - 文章列表页面实时更新
  • 缓存自动失效 - Next.js 缓存标签和路径失效

技术特性

  • 单例模式 - 确保资源效率和一致性
  • 职责分离 - 每个类专注于特定功能领域
  • 向后兼容 - 完全兼容旧版本 API
  • 错误处理 - 完善的错误处理和日志记录
  • 非阻塞请求 - 不影响 WordPress 后台性能
  • ACF 支持 - 完整支持 Advanced Custom Fields 插件

版本信息

当前版本 1.0.0
WordPress 要求 5.0+
PHP 要求 7.4+
许可证 GPL v2 或更高版本

快速开始

  1. 安装插件

    将插件文件上传到 /wp-content/plugins/fd-websocket-push/ 目录

  2. 配置常量

    在 wp-config.php 中添加必要的常量定义

  3. 激活插件

    在 WordPress 后台激活 FD WebSocket Push 插件

  4. 验证功能

    检查日志确认插件正常工作

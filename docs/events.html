事件系统

事件系统概述

FD WebSocket Push 插件的事件系统负责监听 WordPress 中的各种变化，并将这些变化实时推送到前端应用。系统支持多种事件类型，每种事件都有特定的数据结构和目标受众。

文章事件 (Post Events)

post:updated

触发时机: 文章被更新时

目标受众: 基于文章访问权限确定

数据结构:

{
  "event": "post:updated",
  "target": "public|authenticated_users|level_X",
  "data": {
    "postId": 123,
    "postType": "post",
    "status": "publish",
    "shortUuid": "abc123",
    "slug": "sample-post"
  }
}

post:updated-for-lists

触发时机: 已发布文章被更新时

目标受众: 公开用户

数据结构:

{
  "event": "post:updated-for-lists",
  "target": "public",
  "data": {
    "postId": 123,
    "postType": "post",
    "status": "publish",
    "shortUuid": "abc123",
    "slug": "sample-post",
    "title": "文章标题",
    "excerpt": "文章摘要",
    "date": "2024-01-01 12:00:00",
    "modified": "2024-01-01 12:30:00",
    "categories": [
      {"id": 1, "slug": "tech", "name": "技术"}
    ],
    "tags": [
      {"id": 5, "slug": "wordpress", "name": "WordPress"}
    ],
    "customTaxonomies": {
      "company": [
        {"id": 10, "slug": "example-corp", "name": "示例公司"}

    }
  }
}

分类法事件 (Taxonomy Events)

tag:updated

触发时机: 标签被创建、编辑或删除时

目标受众: 公开用户

数据结构:

{
  "event": "tag:updated",
  "target": "public",
  "data": {
    "termId": 15,
    "taxonomy": "post_tag",
    "slug": "new-tag",
    "name": "新标签"
  }
}

category:updated

触发时机: 分类被创建、编辑或删除时

目标受众: 公开用户

数据结构:

{
  "event": "category:updated",
  "target": "public",
  "data": {
    "termId": 8,
    "taxonomy": "category",
    "slug": "technology",
    "name": "技术"
  }
}

taxonomy:updated

触发时机: 自定义分类法条目被创建、编辑或删除时

目标受众: 公开用户

数据结构:

{
  "event": "taxonomy:updated",
  "target": "public",
  "data": {
    "termId": 25,
    "taxonomy": "company",
    "slug": "example-corp",
    "name": "示例公司"
  }
}

list:item-added / list:item-removed

触发时机: 文章的分类法关联发生变化时

目标受众: 公开用户

数据结构:

{
  "event": "list:item-added",
  "target": "public",
  "data": {
    "postId": 127,
    "affectedTerms": [
      {
        "taxonomy": "category",
        "slug": "news",
        "termId": 12
      },
      {
        "taxonomy": "post_tag",
        "slug": "breaking",
        "termId": 18
      }
    ]
  }
}

支付事件 (Payment Events)

post:unlocked

触发时机: 用户成功支付解锁文章时

目标受众: 特定用户 (user_X)

数据结构:

{
  "event": "post:unlocked",
  "target": "user_123",
  "data": {
    "postId": 128
  }
}

目标受众类型

public 所有用户，包括未登录用户
authenticated_users 所有已登录用户
level_X 特定会员等级的用户（X 为等级 ID）
user_X 特定用户（X 为用户 ID）

事件触发条件

文章事件触发条件

  • 文章类型检查 - 只处理公开的文章类型
  • 状态检查 - 某些事件只在特定状态下触发
  • 权限检查 - 根据文章访问权限确定推送目标
  • 更新检查 - 区分新建和更新操作

分类法事件触发条件

  • 分类法类型检查 - 只处理公开的分类法
  • 元数据过滤 - 忽略内部和临时元数据
  • ACF 支持 - 支持 ACF 字段更新
  • 关联变化检测 - 检测文章与分类法的关联变化

支付事件触发条件

  • 订单类型验证 - 只处理文章解锁订单
  • 支付状态确认 - 确认支付成功
  • 用户身份验证 - 验证用户身份
  • 文章存在性检查 - 确认文章存在

事件数据字段说明

通用字段

event 事件类型标识符
target 目标受众房间
data 事件相关数据

文章相关字段

postId 文章 ID
postType 文章类型
status 文章状态
shortUuid 文章短 UUID（用于前端路由）
slug 文章别名
title 文章标题
excerpt 文章摘要

分类法相关字段

termId 分类法条目 ID
taxonomy 分类法名称
slug 条目别名
name 条目名称

⚠️ 注意事项

  • 所有 WebSocket 推送都是非阻塞的，不会影响 WordPress 后台性能
  • 事件数据会根据用户权限进行过滤，确保安全性
  • 大量操作时可能产生大量事件，建议监控 WebSocket 服务器性能
  • 事件推送失败不会影响 WordPress 正常功能

安装配置

系统要求

WordPress 版本 5.0 或更高版本
PHP 版本 7.4 或更高版本
内存要求 最少 128MB（推荐 256MB）
必需扩展 curl, json
可选扩展 ACF (Advanced Custom Fields)

步骤 1: 下载和上传插件

方法一：手动上传

  1. 下载插件文件

    从 GitHub 或其他来源下载 fd-websocket-push 插件文件夹

  2. 上传到服务器

    将整个 fd-websocket-push 文件夹上传到 /wp-content/plugins/ 目录

  3. 验证文件结构

    确保文件结构如下：

    /wp-content/plugins/fd-websocket-push/
├── fd-websocket-push.php
├── includes/
│   ├── class-helper.php
│   ├── class-cache-invalidator.php
│   ├── class-websocket-pusher.php
│   ├── class-post-event-handler.php
│   ├── class-taxonomy-event-handler.php
│   └── class-payment-event-handler.php
└── README.md

方法二：通过 WordPress 后台上传

  1. 打包插件

    将 fd-websocket-push 文件夹压缩为 ZIP 文件

  2. 上传插件

    在 WordPress 后台 → 插件 → 安装插件 → 上传插件，选择 ZIP 文件上传

  3. 安装插件

    点击"现在安装"按钮完成安装

步骤 2: 配置必需常量

在 wp-config.php 文件中添加以下常量定义：

// WebSocket 推送密钥
define( 'FD_WEBSOCKET_PUSH_SECRET', 'your-secure-websocket-secret-key' );

// Next.js 缓存失效密钥
define( 'REVALIDATE_SECRET', 'your-secure-revalidate-secret-key' );

⚠️ 安全提示

  • 使用强密码生成器生成安全的密钥
  • 密钥长度建议至少 32 个字符
  • 不要在代码中硬编码密钥
  • 定期更换密钥以提高安全性

密钥生成示例

您可以使用以下方法生成安全的密钥：

# 使用 OpenSSL 生成随机密钥
openssl rand -base64 32

# 使用 WordPress 密钥生成器
# 访问：https://api.wordpress.org/secret-key/1.1/salt/

# PHP 生成示例
bin2hex(random_bytes(32))

步骤 3: 激活插件

  1. 进入插件管理页面

    在 WordPress 后台导航到 插件 → 已安装的插件

  2. 找到插件

    在插件列表中找到 "Lingcoo WebSocket Push"

  3. 激活插件

    点击"激活"按钮启用插件

  4. 验证激活

    激活成功后，插件状态应显示为"已激活"

步骤 4: 验证安装

检查错误日志

插件激活后，检查 WordPress 错误日志中是否有相关消息：

# 成功激活的日志示例
[Lingcoo WebSocket Push] Lingcoo WebSocket Push plugin activated

# 配置错误的日志示例
[Lingcoo WebSocket Push ERROR] FD_WEBSOCKET_PUSH_SECRET not defined
[Lingcoo WebSocket Push ERROR] REVALIDATE_SECRET not defined

测试基本功能

  1. 创建测试文章

    创建一篇新文章并发布，检查日志中是否有推送事件

  2. 更新文章

    编辑并保存文章，验证更新事件是否触发

  3. 检查 WebSocket 连接

    确认 WebSocket 服务器能够接收到推送事件

高级配置选项

自定义 WebSocket 服务器地址

如果您的 WebSocket 服务器不在默认地址，可以通过过滤器自定义：

// 在主题的 functions.php 中添加
add_filter( 'fd_websocket_push_server_url', function( $url ) {
    return 'http://your-websocket-server:8080/push-event';
} );

自定义前端服务器地址

如果您的 Next.js 前端服务器不在默认地址：

// 自定义前端服务器地址
add_filter( 'fd_websocket_push_frontend_url', function( $url ) {
    return 'http://your-frontend-server:3000';
} );

禁用特定事件类型

您可以选择性地禁用某些事件类型：

// 禁用文章插入事件
add_filter( 'fd_websocket_push_enable_post_insert', '__return_false' );

// 禁用分类法事件
add_filter( 'fd_websocket_push_enable_taxonomy_events', '__return_false' );

性能优化建议

  • 对象缓存 - 启用 Redis 或 Memcached 对象缓存以提高性能
  • 日志管理 - 定期清理 WordPress 错误日志文件
  • 网络优化 - 确保 WebSocket 服务器与 WordPress 之间的网络延迟较低
  • 资源监控 - 监控服务器资源使用情况，特别是内存和 CPU
  • 批量操作 - 避免在短时间内进行大量文章操作

🔧 故障排除快速检查

  • 确认 PHP 版本符合要求（7.4+）
  • 检查 WordPress 错误日志
  • 验证常量是否正确定义
  • 确认 WebSocket 服务器正在运行
  • 检查网络连接和防火墙设置

## 🚀 在线访问

如果您正在查看本地文件，建议通过 Web 服务器访问以获得最佳体验：

```bash
# 使用 Python 启动本地服务器
cd fd-websocket-push/docs
python -m http.server 8000

# 或使用 Node.js
npx http-server -p 8000

# 然后访问 http://localhost:8000
```
